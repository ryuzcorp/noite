### Fixed

- **The edge always serves the newest route table.** A Caddy reload no longer reinstates the boot-time file over a table the runner pushed since, a drained edge no longer serves the table it released (and refuses requests as if it were still booting), and a correction pushed under an already-live generation now applies instead of being dropped as identical.
- **The edge refuses route combinations its static config cannot act on** — a gate on a tenant or custom host, a wake on the control plane, a rewrite outside git and the fallback page, or rate limits on a deny route — with a 400 at push instead of silently ignoring them. Every table the runner emits today still validates.
- **A configured edge rate limit is a real ceiling.** The budget is derived from the window and rounded down (`floor(rpm × 10 s / 60 s)`), and below 6/min the window widens to an exact divisor of a minute, so 1/min is one request per 60 s instead of six a minute and 100/min is 100, not 102.
- **`Retry-After` reports the real remaining time.** It is the time until enough of the key's stamps leave the window for it to admit again, so after a lowered rate a client that honours the header is admitted instead of looping on 429s.
- **A request refused by the app ceiling no longer spends the client's budget.** The client zone and the app zone are decided in one step, and both record a stamp only when both admit the request.
- **Eviction and sweep no longer clear a live throttle.** Eviction only drops keys whose budget has recovered, a sweep keeps every key still inside its window, and a full zone with nothing evictable admits new keys uncounted until its windows pass instead of resetting a limit a client could then spray past.
- **A tenant slug can no longer share a platform rate-limit zone.** Zones now carry their owner (`platform:client:<kind>`, `app:<slug>:client`, `app:<slug>:all`), so an app slugged `control`, `preview` or `fallback` no longer draws from the platform host's per-visitor budget. The first push after the upgrade sweeps the old names.
