### Added

- The Metrics tab's Analytics cards are back: **Browsers**, **Operating systems**, **Paths** and **Referrers** over the selected window (24 h / 7 d / 30 d), live-refreshing with the other tiles. They are fed by the access log into one `metrics.app_hour_dim` row per (app, environment, hour, kind, value), written in the line's own transaction alongside the hourly counters — so they count exactly the fleet-served requests the counters count, never the edge's own answers. Each kind keeps its top 10 values with the rest folded into a trailing `(other)`; paths and referrers are capped at 50 distinct values per hour (`(other)` takes the overflow), and referrers store only the bare host (named social/search sources by name, empty as `Direct`) — never a path or query. The new `GET /v1/apps/{id}/metrics/breakdown?hours=&environmentId=` read serves them with the same scope and auth as `/metrics`.
