### Fixed

- **A tenant slug can no longer share a platform rate-limit zone.** Platform hosts used fixed zone names (`client_control`, `client_preview`, `client_fallback`, `client_api`, `client_git`) while an app's zones were `client_<slug>`/`app_<slug>`, so an app with the slug `control`, `preview` or `fallback` shared the platform host's per-visitor budget: a visitor's requests to the app and to the platform host drew from one budget, and the app's own limit (say 1/min) throttled that visitor on the control UI. Zone names now carry their owner — `platform:client:<kind>` and `app:<slug>:client` / `app:<slug>:all` — so a slug can never name a platform zone. The edge treats zone names opaquely; the first push after the upgrade sweeps the old names, so in-flight throttles restart. No configuration change is required.
