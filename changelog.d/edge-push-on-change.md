### Changed

- **An idle runner no longer re-sends the whole edge route table every 5 s.** The reconcile tick builds the table as before, but POSTs it only when the table changed since the file was written; otherwise it asks the edge which generation it serves (`GET /edge/routes`, a few bytes over loopback) and skips the push when the answer is the current one. A Caddy that restarted and lost its in-memory table reports a different generation, so the next tick pushes again; a refused or unanswered push is still retried on the next tick. Because that probe reports the generation and not the routes (the edge applies an equal generation with different routes as a correction), one full push still goes out every five minutes, so an equal-generation correction lands within that window. No configuration change.
