### Added

- Apps created by a GitHub import can force sync with the origin from the Overview tab (**Sync from GitHub**, push role). A sync writes one new commit with the origin's tree and deploys it; the app's history is kept. When the sync would overwrite commits made in Noite, the button asks for confirmation first, and the sync is refused if the origin moved since the status was read. On a protected `main` (pull requests required) a sync needs an admin, like any other direct write. The same operation is available to agents as the `sync_from_github` MCP tool. There is no CLI for it: syncing is an app-page and agent action, and the CLI has no app-page surface to carry it.
