### Fixed

- **Switching pages or tabs no longer flashes an error.** The page's one stream connection is replaced whenever the visible feeds change, and the hub told every panel that the replaced link had closed while the replacement was still opening. A panel read that as "Live updates are unavailable. Reload the page to try again." and kept it until its new stream's first frame landed — so the Deployments, Metrics, Errors, Events and Logs tabs, the apps list and the app page all painted an error over a load that was already in flight. The hub now announces only the replacement (the old link's teardown is not a fact about the panels), and a feed that starts connecting again returns to loading — a skeleton when it has no value, its last value when it has one — instead of keeping a problem it may already have left behind. A server render also paints the loading state for a feed the browser has not tried to open, never an offline problem.
