### Fixed

- **A slow static asset can no longer be answered with a 15 s JSON 504 (the e2e "flake wave").** The control UI shipped `run_worker_first: true`, so every `/assets/*` request started the Worker — and Void's generated pages fallback serves a chunk by fetching `env.ASSETS` _inside_ the Hono app. That put static files behind the whole middleware chain (the better-auth session, the per-request D1 bootstrap, the rate limit) and, decisively, behind `src/middleware/01-timeout.ts`'s 15 s action bound: `lane-caddy-access.log` showed shared chunks (`pages-client`, `Data`, `branches`, `errors`, `copy-button`, `rolldown-runtime`) answered 504 at exactly 15.00–15.01 s with a 29-byte `{"error":"Request timed out"}` body while the same URLs answered 200 in ~10 ms in the same seconds, the page HTML in 3–8 ms and nothing restarted or OOM'd. A bundle that arrives as a 504 never executes, so the island never hydrated and every locator on that page timed out 30 s later — the clustered create/admin/domains/environments/editor failures. A 504 also _ends_ the request that was awaiting the isolate-level manifest single-flight, which celld then drops ("celld drops a request's pending work when that request answers or its client leaves" — the same mechanism as the dropped DB setup pass), poisoning that isolate for every later asset request. `run_worker_first` is now `["/**", "!/assets/*"]`: celld serves the fingerprinted bundle from its own asset resolver with the same `_headers` policy (the `/assets/*` immutable cache rule and the COOP/COEP/CORP isolation headers, read from `public/_headers` at deploy), so no action bound, session read, D1 read or orphaned pass stands between the browser and its chunks. A missing file still falls through to the Worker, so the app's 404 handling is unchanged. The action timeout also exempts `/assets/*` (`routeTimeout` reports `why: "static"`), so a static read that still reaches the Worker — the miss fall-through, a direct-to-worker request, or a future config regression — is never converted into a JSON 504. `apps/noite/src/lib/asset-routing.test.ts` asserts both halves.
