# Introduction

Noite is a tiny self-hostable PaaS for [celld](https://celld.dev/): user accounts (passkeys), apps, `{slug}.{BASE_DOMAIN}` subdomains, thin deploy/build logs and status. It fits on one small server.

One `docker compose up -d` runs four services from `docker/compose.yaml`:

- **rustfs** — the S3 fleet bucket (`git/` tip bundles, `fleets/` tenant celld, `control/` UI worker + its D1). Optional: point the stack at your own S3 instead.
- **runner** — the Rust deploy pipeline: Git smart-HTTP, builds, one celld fleet per app, telemetry aggregation, and the Caddyfile the edge reloads.
- **control** — the Oxide control UI on a celld node; its worker bundle is baked into the image and self-deployed on first boot.
- **caddy** — the edge: per-host TLS with on-demand certificates, routing to the UI, the API and tenant apps.

Get started from a checkout:

```bash
cp .env.example .env
make up      # build both images and start the stack
make logs
make doctor  # verify the install
```

| URL                            |                       |
| ------------------------------ | --------------------- |
| http://localhost:9080          | control UI (passkeys) |
| http://api.localhost:9080      | runner API            |
| `http://{slug}.localhost:9080` | deployed apps         |

Then deploy the sample app: `cd apps/noite/test && ./deploy.sh`.

Real domains, external S3, Coolify, image-only hosts, volumes and backups: [Deployment](/deployment).
