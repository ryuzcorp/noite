Noite is a tiny self-hostable PaaS for [celld](https://celld.dev/docs/). One image runs accounts (passkeys), apps, `{slug}.{domain}` subdomains, and deploy logs on a single small server.

Two audiences, two tracks. App developers ship against an existing install and never need the operator track.
