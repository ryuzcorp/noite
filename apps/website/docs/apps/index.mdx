---

An app is a celld Worker with a `git` remote. The owner creates it in the UI; deploys follow every push to that remote.

<Steps>
<Step title="Deploy">
Push code over Git smart-HTTP or from CI. Each push builds, releases, and goes live behind `http://<slug>.<domain>`.
</Step>
<Step title="Configure">
Env vars, custom domains, collaborators, source edits, and storage inspection — all from the app detail page.
</Step>
<Step title="Observe">
Runtime logs, request metrics with spans, product-analytics events, and idle sleep behavior.
</Step>
</Steps>

App slugs are 1–48 chars: lowercase letters, digits, hyphens, starting and ending with a letter or digit. Reserved: `_control`, `app`, `api`, `git`.
