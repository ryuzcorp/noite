An app is a Worker or a static site, run by celld, with a `git` remote. The owner creates it in the UI; deploys follow every push to that remote.

<Steps>
<Step title="Deploy">
Push code over Git smart-HTTP or from CI. Each push builds, releases, and goes live behind `https://<slug>.<domain>`.
</Step>
<Step title="Configure">
Env vars, custom domains, rate limits, collaborators, source edits, and storage inspection — all from the app detail page.
</Step>
<Step title="Observe">
Runtime logs, request metrics with spans, errors, product-analytics events, and idle sleep behavior.
</Step>
</Steps>

New here? [Your first app, in order](/apps/deploy#your-first-app-in-order) is the short path. Limits (quotas, build size and time, rate limits, memory) are on [Limits](/reference/limits).

App slugs are 1–48 chars: lowercase letters, digits, hyphens, starting and ending with a letter or digit. Reserved: `_control`, `app`, `api`, `git`.
